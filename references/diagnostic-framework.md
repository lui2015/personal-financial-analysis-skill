# 诊断框架：指标体系 · 六维评分 · 问题检测库

## 一、必算的 12 个指标

| # | 指标 | 公式 | 健康区间 | 说明 |
|---|---|---|---|---|
| 1 | 净资产 | 金融资产 + 不动产估值 − 总负债 | — | 唯一的"身家"口径 |
| 2 | 金融资产市值 | Σ 在持仓位最新价 | — | 可动用资产 |
| 3 | 全口径浮动盈亏 | (金融市值+房产估值) − (金融成本+房产成本) | — | **必算**，常与分口径结论相反 |
| 4 | 资产负债率 | 总负债 / 总资产（含不动产） | < 50% | > 60% 为高杠杆 |
| 5 | 金融资产负债率 | 总负债 / 金融资产 | < 100% | 衡量"立刻还清"的能力 |
| 6 | 负债清偿率 | 已结清 / 原负债 | — | 进度感知 |
| 7 | 流动性覆盖月数 | 现金类 / 月支出 | 3–6 个月 | 月支出未知时按月收入 70% 估 |
| 8 | 被动收入占比 | 被动收入 / 总收入 | 目标 ≥ 5% 起步 | **最重要的单一指标** |
| 9 | 权益/固收比 | 权益类市值 : 固收+现金 | 按年龄与负债定 | 见下方配置基准 |
| 10 | 单一产品集中度 | 最大单只 / 金融资产 | ≤ 15% | > 25% 为红线 |
| 11 | 前三持仓集中度 | Top3 / 金融资产 | ≤ 45% | > 60% 为红线 |
| 12 | 储蓄贡献率 | (资产增量 − 累计投资收益) / 资产增量 | — | 回答"涨的是储蓄还是收益" |

### 指标 12 的算法（高信息量，容易被漏）

```
期初金融资产 A0，期末 A1，期末累计投资收益 P1，期初累计投资收益 P0
资产增量 ΔA = A1 − A0
投资贡献 = P1 − P0
储蓄贡献 = ΔA − (P1 − P0)
储蓄贡献率 = 储蓄贡献 / ΔA
```

实测典型个人表：储蓄贡献率 85%–95%。把这个数字摆出来，用户才能理解"我不是不会投资，我是还没开始靠投资"。

### 被动收入口径修正（必做）

很多表里「被动稳定收入」只填了零散几块钱，因为债基/货基的收益被计进了"资产浮动"。
修正算法：

```
真实被动稳定收入(月) ≈ 固收类市值 × 预估年化 / 12
  货币基金 年化 1.2%–1.5%
  短债基金 年化 2.0%–2.8%
  中长债   年化 2.5%–3.2%
修正后被动收入占比 = (真实被动稳定 + 股息/分红) / 总收入
```

报告里要把**账面值**和**修正值**都写出来，并说明差异原因。

## 二、六维评分（0–100）

| 维度 | 评分依据 | 基准线 |
|---|---|---|
| **资产结构** | 大类配置合理性、是否存在资产类别缺口 | 75 |
| **负债健康** | 有无高息负债、清偿进度、有无逾期 | 75 |
| **流动性管理** | 现金覆盖月数是否在 3–6 | 75 |
| **收益能力** | 全口径收益率、近 3 个月动能 | 70 |
| **被动收入** | 修正后被动收入占比 | 50 |
| **风险分散** | 集中度、持仓数量、同质化程度 | 75 |

### 打分锚点

**资产结构**
- 90：权益/固收比例匹配年龄与负债，7 大类资产齐备，无单类超 60%
- 70：比例大体合理但缺 1–2 个类别（如无黄金、无高股息）
- 50：单一大类 > 70%，或完全无权益 / 完全无固收
- 30：资产集中在单一类别且与风险承受能力明显错配

**负债健康**
- 90：无信用类负债，仅低息房贷，清偿进度正常
- 70：有少量信用类负债但金额小 / 已在偿还
- 50：存在结清率 0% 的循环信用负债（花呗、信用卡）
- 30：信用类负债 > 金融资产 20%，或有逾期

**流动性管理**
- 90：3–6 个月，且集中在单一高流动性账户
- 80：6–9 个月（冗余，机会成本）
- 60：> 9 个月（严重冗余）或 1.5–3 个月
- 30：< 1.5 个月

**收益能力**
- 按**全口径**年化收益率打分：> 6% → 85；3–6% → 70；0–3% → 50；< 0 → 35
- 近 3 个月动能衰减（最近 3 月收益 < 前 3 月的 30%）额外扣 5 分

**被动收入**（修正后占比）
- ≥ 20% → 85；10–20% → 70；5–10% → 55；1–5% → 30；< 1% → 10

**风险分散**
- 单一产品 > 30% 直接 ≤ 50 分
- Top3 > 60% 扣 15 分
- 存在 2 只以上同赛道重叠基金扣 10 分
- 雇主/前雇主股票 > 10% 扣 10 分

### 总评

加权平均（资产结构 20% · 负债健康 20% · 流动性 15% · 收益能力 20% · 被动收入 15% · 风险分散 10%），映射：

| 分数 | 评级 |
|---|---|
| 85+ | 健康 / Excellent |
| 70–84 | 良好 / Good |
| 55–69 | 亚健康 / Fair |
| 40–54 | 需干预 / Weak |
| < 40 | 高风险 / Critical |

## 三、问题检测库（24 条）

按 P0（正在损失钱）/ P1（结构性低效）/ P2（管理与记账）分级。

### P0 — 立刻损失现金

| ID | 检测条件 | 问题 |
|---|---|---|
| P0-1 | 存在结清率 0% 的信用卡/花呗/白条，且现金类 > 该金额 10 倍 | 高息负债与低息资产并存，负利差 13–17% |
| P0-2 | 信用卡分期类贷款余额 > 3 万 | 信用卡学费/消费分期折算年化 12–15%，远高于固收收益 |
| P0-3 | 不动产行收益率 ≥ +99% 或 总收益 == 成本 | 公式符号错误，系统性高估财富 |
| P0-4 | 某类资产"最新价"列连续 ≥ 2 期留空 | 估值未更新，所有基于它的结论失真 |
| P0-5 | 总负债 > 总资产 | 技术性破产，需立即重整 |
| P0-6 | 流动性覆盖 < 1.5 个月且有信用负债 | 现金流断裂风险 |
| P0-7 | 小计/总计的 `SUM(X{a}:X{b})` 区间 ≠ 实际数据行区间 | 求和漏行，总资产被静默少算（见 data-extraction 缺陷 B） |
| P0-8 | editor_sdk 实时值与 openpyxl 缓存值不一致 | 表格公式缓存陈旧，用户看到的数字本身是错的 |

### P1 — 结构性低效

| ID | 检测条件 | 问题 |
|---|---|---|
| P1-1 | 单一产品 > 25% | 集中度超红线，单一管理人/产品风险 |
| P1-2 | Top3 > 60% | 头部过度集中 |
| P1-3 | 修正后被动收入占比 < 5% | 财务自由度接近 0，收入 100% 依赖劳动 |
| P1-4 | ≥ 2 只同赛道基金且均亏损 > 20% | 同质化重叠 + 缺少卖出纪律 |
| P1-5 | 雇主/前雇主股票 > 10% | 薪酬与资产双重押注同一主体 |
| P1-6 | 单一行业/主题基金亏损 > 30% 仍持有且无处置记录 | 缺少退出条件 |
| P1-7 | 权益占比 < 20% 且年龄 < 45 且收入稳定 | 过度防御，长期跑不过通胀 |
| P1-8 | 权益占比 > 70% 且有大额短期负债 | 风险错配 |
| P1-9 | 储蓄贡献率 > 85% | 资产增长几乎全靠工资，投资系统尚未生效 |
| P1-10 | 近 3 月收益 < 前 3 月 30% | 收益动能衰减 |

### P2 — 管理与记账

| ID | 检测条件 | 问题 |
|---|---|---|
| P2-1 | 流动性覆盖 > 8 个月 | 现金冗余，机会成本高 |
| P2-2 | 无黄金/大宗 敞口 | 缺通胀与汇率对冲 |
| P2-3 | 无高股息/红利类资产 | 缺可见现金流资产 |
| P2-4 | 表内无任何保险条目且有负债 | 保障缺口（最高频，且性价比最高的修补项） |
| P2-5 | 已清仓行 > 在持行数量 | 表格卫生差，影响判断效率 |
| P2-6 | `#DIV/0!` ≥ 5 处 | 公式残留 |
| P2-7 | 相邻 sheet 月份间隔 > 1 个月 | 记账断层，趋势分析有盲区 |
| P2-8 | 某项负债/资产总额单月变动 > 30% 且无对应现金流 | 口径变更未追溯历史，趋势图存在断点 |
| P2-9 | 无月度现金流表 | 只有存量视角，无法回答"钱去哪了" |
| P2-10 | 资金在多个低息账户间频繁大额进出 | 闲置期机会成本，建议归集 |

### 输出格式

每条问题必须写成：

```
【优先级】问题标题（带量化结论）
  现状：<具体数字 + 对比参照>
  后果：<为什么这是问题，用户会损失什么>
  ▸ 处置建议：<可执行动作 + 预期收益/节省金额>
```

**反例**（禁止）："建议优化资产结构，提高配置效率。"
**正例**："清零花呗 ¥3,085.87 + 招行信用卡 ¥1,467.23，从余额宝直接划转。这两笔循环计息年化约 14–18%，余额宝年化 1.3%，净收益差 13–17 个百分点。"
