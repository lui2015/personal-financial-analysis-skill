# 建议生成规则 · 目标配置模型

## 一、排序总原则：按"确定性收益"排，不按金额排

| 动作 | 确定性年化收益 | 优先级 |
|---|---|---|
| 清偿花呗/信用卡循环账单 | **14–18%**（确定） | ①最高 |
| 提前偿还信用卡分期类贷款 | **12–15%**（确定） | ② |
| 清偿消费贷/网贷 | 8–12%（确定） | ③ |
| 配置红利/固收 | 2–5%（不确定） | ④ |
| 提前偿还房贷（利率 ≤ 3.5%） | 3–3.5%（确定） | ⑤ |
| 增配权益 | 长期 6–8%（高波动） | ⑥ |

**一句话逻辑**：还掉一笔年化 15% 的债，等于买到一只保证年化 15% 且零波动的产品——全市场不存在这种产品。所以还债永远排在配置之前。

**例外**：提前还款前必须确认①有无违约金 ②是否影响征信额度 ③是否需保留流动性缓冲。

## 二、三阶段模板

### 第一阶段 · 0–1 个月（确定性收益）
1. 清零所有结清率 0% 的循环信用负债（逐笔列出金额与资金来源账户）
2. 提前偿还信用卡分期类贷款（给出具体金额 + 年省息测算 + 保留的现金缓冲）
3. 修复表格数据错误（公式符号、估值更新、口径标注）

### 第二阶段 · 1–3 个月（结构优化）
4. 现金压缩到 3–4 个月支出，释放资金用于还债
5. 拆分超红线的集中持仓（给出"保留多少 / 转出多少 / 转到哪 3 类"）
6. 清理小额"鸡肋"仓位（判定标准见下）
7. 减持雇主/前雇主股票（分批，给出节奏）

### 第三阶段 · 3–12 个月（长期机制）
8. 建立核心-卫星目标配置
9. 被动收入工程化（给出 12 个月量化目标 + 三条路径）
10. 补齐保险缺口（给出具体险种 + 保额 + 年缴预算）
11. 房贷策略（按利率分档给策略）
12. 记账系统升级（补月度现金流表 / 应急金专项 / 保单台账）

## 三、关键判定标准

### 小额"鸡肋"仓位
满足以下任一即判定：
- 单笔市值 < 金融资产 1%
- 单笔市值 < 5,000 元

处置原则：
- **盈利的** → 止盈了结，不要因为"还在涨"而留着
- **亏损且与现有持仓同质** → 合并到保留的那一只
- **亏损但属于战略配置方向**（如海外、黄金）→ **不要卖，反而应该加到目标仓位**

最后一条最容易搞反。海外指数持仓 2,000 元不是"鸡肋仓位该清理"，是"战略方向只建了 1% 的仓"。

### 集中度拆分方案模板

```
<产品名> 现 ¥X（占 Y%）→ 保留 ¥Z（≤15%）
转出 ¥(X−Z) 分三份：
  · 同业存单指数基金   1/3   （低波动、费率低）
  · 国债/政金债 ETF    1/3   （利率敏感度分散）
  · 另一家管理人的短债  1/3   （管理人风险分散）
硬规则：单一产品 ≤ 15%，单一管理人 ≤ 25%
```

### 保险缺口（表内无保险时必出）

```
定期寿险保额 ≥ 总负债 + 5 年生活支出
百万医疗险：年缴几百元，杠杆最高，必配
重疾险：保额 ≥ 2 年收入（通常 50 万起）
配置顺序：百万医疗 → 定期寿险 → 重疾 → 意外
```

### 房贷策略分档

| 执行利率 | 策略 |
|---|---|
| ≤ 3.5% | 不提前还。优先级低于所有信用负债，甚至低于配置红利资产 |
| 3.5%–4.5% | 高息债清零后，用年终奖部分偿还 |
| > 4.5% | 优先级提到信用分期之后、配置之前；同时查是否可转 LPR / 转贷 |

## 四、目标配置模型

### 基准模型（按"年龄 + 负债"双因子）

权益上限 = `min(100 − 年龄, 100 − 金融资产负债率) × 调整系数`

调整系数：收入稳定 1.0 / 收入波动 0.8 / 有大额短期支出计划 0.6

### 七类资产模板

| 类别 | 作用 | 建议区间 |
|---|---|---|
| 现金/货基 | 应急金，3–4 个月支出 | 8–15% |
| 短债·同业存单·政金债 | 负债安全垫，核心仓 | 35–55% |
| A 股宽基（300/500） | 长期增长主力 | 10–20% |
| 红利低波 | **可见现金流**，股息率 4–5% | 8–12% |
| 海外（纳指100/标普） | 地域与货币分散 | 7–12% |
| 个股 | 仅保留有认知的核心标的 | ≤ 10% |
| 黄金 ETF | 通胀与汇率对冲 | 2–5% |

### 输出要求

1. 必须给**当前 vs 目标**的并列柱状对比图，横轴为上述七类
2. 两组数据各自必须**合计 100%**（算完检查一遍，这一步很容易算错）
3. 目标配置的基数应是**还完高息债之后的剩余金融资产**，不是当前总额
4. 配文必须说明：权益比例从 X% → Y%，但通过宽基化 + 新增红利/黄金，**组合波动率不升反降**，预期年化从 A% → B%

## 五、被动收入工程化模板

```
当前（修正后）被动收入占比 X%  →  12 个月目标 5%（≈¥N/月）

路径一：修正记账口径 —— 固收利息按月确认为被动收入，立即贡献约 A%
路径二：配置红利低波 ¥M（股息率 4.5%），贡献约 B%
路径三：每月工资固定 20% 自动定投，不做择时

验收标准：「赚钱效率」一行里，非工资部分占比 ≥ 5%
```

## 六、语言风格

- **直给结论，不铺垫**。开头就是"你的表里有两处错误，正在系统性高估财富"。
- **每个判断后面跟数字**。不写"集中度偏高"，写"单一产品 33.4%，前三合计 63.7%"。
- **允许有立场**。"低风险 ≠ 无风险，单一产品不该押三分之一"比"建议适度分散"有用得多。
- **指出用户做对的地方**。负债端清零两笔学贷是真本事，要明确肯定——报告不能只有批评，否则用户不会执行。
- **不说教，不道德评判**。不要出现"你应该更有理财意识"这类话。
