# 💰 personal-financial-analysis-skill

> 个人资产负债表财务体检与投资诊断 —— 一个 WorkBuddy / Claude Code Agent Skill

把一份个人「资产 & 负债」记账表，变成一份能真正改变行动的**单文件 HTML 诊断报告**。

---

## 它解决什么问题

个人记账表通常只有「存量」视角：有什么、值多少。这个技能补上缺失的三层：

| 层 | 内容 |
|---|---|
| **结构诊断** | 配置是否合理、集中度是否危险、有没有同质化重叠 |
| **效率诊断** | 资产增长到底来自储蓄还是投资、被动收入进度如何 |
| **数据质量诊断** | 表里的公式错误、口径变更、记账断层 |

第三层最容易被忽略，却最常导致人对自己的财富产生**错误认知**。实测一份真实记账表就查出三处缺陷：房产收益率公式引用错列导致显示 `+100%`（实际 -23.2%）、总计行求和范围漏算 3 行、以及全表公式缓存陈旧。

最后输出**按优先级排序、可直接执行**的行动方案。

## 核心方法论

### 1. 建议按「确定性收益」排序，不按金额排序

| 动作 | 确定性年化 | 优先级 |
|---|---|---|
| 清偿花呗/信用卡循环账单 | **14–18%**（确定） | ① |
| 提前偿还信用卡分期类贷款 | **12–15%**（确定） | ② |
| 配置红利/固收 | 2–5%（不确定） | ④ |
| 增配权益 | 长期 6–8%（高波动） | ⑥ |

> 还掉一笔年化 15% 的债，等于买到一只保证年化 15% 且零波动的产品——全市场不存在这种产品。所以还债永远排在配置之前。

### 2. 全口径与分口径必须分开说

不动产的浮亏经常把金融资产的浮盈**全额吃掉**。只报「金融资产 +X%」是误导。

### 3. 被动收入占比是全局最重要的单一指标

它决定了一个人离「资产替工资干活」有多远。注意很多表把债基/货基收益计入「资产浮动」而没确认为「被动收入」，会使该指标严重低估——技能会识别并重算真实值。

## 触发方式

把资产负债表（xlsx / csv / 截图 / 文字清单）丢给 Agent，然后说：

```
帮我系统分析诊断一下，并给出理财投资建议，生成 html
```

其他触发词：资产负债表、财务体检、财务诊断、理财建议、资产配置分析、净资产分析、持仓分析、
`personal finance diagnosis`、`net worth analysis`、`portfolio checkup`、`asset allocation review`

**不适用**：单只股票/基金分析、财经概念科普、上市公司财报分析。

## 关键技术坑（踩过，已固化进文档）

### ⚠️ openpyxl 读个人记账表不可靠

个人记账表常由 WPS/非 Excel 工具保存，**写入公式但不更新计算缓存**。实测同一文件：

| 单元格 | openpyxl 缓存 | 实时重算 | 差异 |
|---|---|---|---|
| 总成本 | 856,332 | **863,168** | 陈旧（上月值） |
| 某货基成本 | 42,053 | **16,208** | 差 2.6 倍 |

且成本列常是反推公式 `=最新价 − 总收益`，**没有独立原始值**，缓存错了无法自救。
判据：公式在 XML 里存成 `==E48-F48`（双等号）即为非 Excel 写入器特征。

### ⚠️ 内联 JS 数组里的中文直引号会炸

中文内容里的 ASCII 直引号 `"` 会提前结束 JS 字符串。统一用 `「」`，写完必须校验：

```bash
python3 - <<'EOF' > /tmp/chk.js
import io,re
s=io.open('<报告路径>',encoding='utf-8').read()
io.open('/dev/stdout','w',encoding='utf-8').write(re.findall(r'<script>(.*?)</script>',s,re.S)[-1])
EOF
node --check /tmp/chk.js
```

### ⚠️ 同表内求和范围不一致

实测 `E47=SUM(E3:E46)` 但 `G47=SUM(G3:G43)`——漏算 3 行。漏掉的行恰好空仓时总数看起来是对的，**一旦有持仓就静默少算**。必须解析各小计公式的 `SUM(X{a}:X{b})` 区间并与真实数据行比对。

完整 7 条见 `SKILL.md`。

本技能产出的是基于你所提供数据的结构化分析与一般性财务规划建议，**不构成任何具体证券、基金或保险产品的投资推荐**。所有数字（尤其房产估值、贷款利率、月度支出）请以实际对账单复核为准；涉及提前还款的操作请先向银行确认违约金条款。
